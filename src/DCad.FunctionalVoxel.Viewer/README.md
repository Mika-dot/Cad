# DCad — функционально-воксельный инженерный просмотрщик

Windows 10/11, .NET 8, WinForms. Простой рабочий интерфейс без отдельного графического движка и декоративных элементов. Реальное вычислительное ядро — соседний проект **DCad.FunctionalVoxel**. Приложение находится в отдельной папке, не смешанной с ранее существующим **DCad.App**.

## Запуск из исходников

```powershell
git clone https://github.com/Mika-dot/Cad.git
cd Cad
git switch feature/functional-voxel-kernel
dotnet run --project src/DCad.FunctionalVoxel.Viewer/DCad.FunctionalVoxel.Viewer.csproj -c Release
```

Также GitHub Actions `Functional voxel kernel CI` проверяет версию под Windows и публикует артефакт **DCad-FunctionalVoxel-Viewer-win-x64** с self-contained исполняемым файлом. Скачивается на странице последнего успешного workflow run, в разделе **Artifacts**. Данный артефакт не является инсталлятором.

### Управление

| Слева | Центральное поле | Справа |
|---|---|---|
| Сфера, параллелепипед, цилиндр, R-разность, R-объединение и R-пересечение; радиусы, разрешение сетки | Интерактивный 3D-изовид: вращение ЛКМ, смещение ПКМ, масштаб колесом; каркасный режим; выбор грани | Срез XY на выбранном Z; поле F либо М0–М4; выбор вокселя мышью; координаты, F, градиент, численные коэффициенты и RGB24 |
| Операции F, ∂F/∂x, ∂F/∂y, ∂F/∂z, ∫Fdx | Геометрия берётся из `FunctionalIsoSurface.Extract`, а не из вручную составленного меша | Объём по знаку вокселей; площадь/объём mesh; проверка topology; оценка ошибок RGB-квантования |

Кнопки **Экспорт OBJ** и **Экспорт CSV** сохраняют геометрию и текущий XY-срез с численными значениями `F`, `dF/dx`, `dF/dy`, `dF/dz`, `M0…M4`. Координаты и геометрические размеры — в миллиметрах.

Сразу после открытия строится демонстрационный пример: сферическое тело минус сквозной цилиндрический канал. Параметры можно изменить и нажать **Построить / рассчитать**.

## Проверки

```powershell
dotnet build DCad.sln -c Release
dotnet run --project src/DCad.FunctionalVoxel.Viewer/DCad.FunctionalVoxel.Viewer.csproj -c Release -- --self-test
```

`--self-test` не открывает интерфейс, но создаёт все шесть демонстрационных моделей средствами ядра, строит изоповерхности, проверяет замкнутость сферы, записывает и читает OBJ и CSV и вычисляет частную производную. Успешный маркер — `VIEWER_SMOKE_PASS`.

## Ограничения

- Это инженерный **софтверный ортографический 3D-просмотрщик**, а не OpenGL: на больших сетках (48–64³) вращение и отрисовка сложных моделей будут медленнее аппаратного рендеринга. Внутри используется упрощённый painter's algorithm без полноценного Z-buffer; перекрывающиеся в проекции участки сложных тел могут отображаться неидеально.
- Программа отображает нулевую поверхность реконструированного поля, а не аналитически точный B-Rep. Для некоторых производных поле пересекает границу расчётного параллелепипеда, и построенная поверхность не обязана быть замкнутой.
- Для демонстрации численного `∫Fdx` задано начальное условие `−0.01` в первом центре X-линии, чтобы избежать совпадения нулевого изоуровня со всеми центрами первого слоя.
- В вырожденных точках R-алгебры или при точном прохождении изоуровня через центр сетки ядро намеренно сообщает ошибку. Она выводится в GUI; численная сингулярность не замаскирована.
- Для отображения пяти М-образов используются не потери при сохранении RGB24, а исходные `double`-коэффициенты. Коды RGB24 и фактическая ошибка восстановления выводятся отдельно.
- Произвольные формулы пользователя, загрузка STEP/STL, параллельные фоны и CAD-история не входят в этот минимальный интерфейс. Исходный `Unified-CAD` и ветка `OpenGL` не изменяются.
