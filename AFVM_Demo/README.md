# AFVM Demo — Adaptive Functional-Voxel Research Demonstrator

Автономный C#/.NET/OpenGL демонстратор гипотезы для темы:

**«Теория адаптивных преобразований функционально-воксельного представления с сохранением локальных геометрических характеристик и R-функциональной алгебры»**.

Это отдельный исследовательский проект в стиле старых веток DCad. Он не меняет `Unified-CAD` и не требует старый SharpGL-код.

## Что показывается

Одна и та же геометрия — сфера с цилиндрическим отверстием — представляется четырьмя способами:

1. `EXACT` — непрерывная аналитическая R-функция;
2. `UNIFORM` — равномерная сетка локальных линейных функций;
3. `ADAPTIVE-DIRECT` — адаптивная функционально-воксельная модель, построенная прямо от аналитического композита;
4. `ADAPTIVE-R` — адаптивная модель, полученная после R-разности уже дискретизированных FV-моделей сферы и цилиндра.

Главный проверяемый маршрут:

```text
A(x), B(x)
   ↓ adaptive FV
A_h, B_h
   ↓ local R-algebra
R(A_h, B_h)
   ↓ error-controlled adaptation
C_h
```

и сравнение `C_h` с аналитическим `R(A,B)` по геометрической ошибке и нормалям.

## Что такое цветные полигоны внутри вокселей

Каждый поверхностный функциональный воксель хранит локальную функцию первого порядка

```text
L_i(x) = f(c_i) + grad(f,c_i) · (x-c_i)
```

Демонстратор вычисляет **точное пересечение локальной плоскости `L_i(x)=0` с AABB своего вокселя**. Поэтому цветной треугольник/четырёх-/пяти-/шестиугольник — не декоративная вставка, а геометрический образ локальной функции. Полигон обрезан гранями конкретного вокселя.

Также можно вывести нормаль `grad(L_i)/|grad(L_i)|`, адаптивные границы ячеек и тепловую карту ошибки.

## Запуск без установленного .NET

Используйте опубликованную `win-x64` self-contained сборку и запускайте:

```text
AFVMDemo.exe
```

В ней лежит собственный .NET runtime. Устанавливать .NET 8 не требуется.

## Запуск из исходников

Нужен .NET SDK 8+:

```powershell
dotnet restore AFVMDemo.sln
dotnet run --project .\src\AFVMDemo\AFVMDemo.csproj -c Release
```

Только численная проверка без OpenGL:

```powershell
dotnet run --project .\src\AFVMDemo\AFVMDemo.csproj -c Release -- --self-test
```

Публикация автономной Windows-сборки:

```powershell
dotnet publish .\src\AFVMDemo\AFVMDemo.csproj -c Release -r win-x64 --self-contained true -o .\publish\win-x64
```

## Управление

- `F1` — режим 2×2: одновременно все четыре представления;
- `1..4` — выбранное представление на весь экран;
- `Tab` — следующее представление;
- `G` — границы uniform/adaptive ячеек;
- `P` — локальные плоскости `L_i(x)=0`, обрезанные вокселями;
- `N` — локальные нормали;
- `H` — heatmap геометрической ошибки;
- `W` — wireframe поверхности;
- `Space` — скрыть поверхность и оставить только FV-структуру;
- `F` — сброс камеры;
- ЛКМ — вращение;
- ПКМ — панорамирование;
- колесо — zoom;
- `Esc` — выход.

В overview:

```text
┌──────────────────────┬──────────────────────┐
│ EXACT                │ UNIFORM FV           │
├──────────────────────┼──────────────────────┤
│ ADAPTIVE DIRECT      │ ADAPTIVE R(A_h,B_h)  │
└──────────────────────┴──────────────────────┘
```

## Параметры эксперимента

```powershell
AFVMDemo.exe --tol 0.025 --depth 6 --uniform-depth 5 --mesh-res 52
```

- `--tol` — допустимая локальная геометрическая ошибка;
- `--depth` — максимальная глубина адаптивного дерева;
- `--uniform-depth` — `2^depth` ячеек на ось uniform baseline;
- `--mesh-res` — только плотность сетки визуализации поверхности, не FV-разрешение.

## Что проверяет self-test

- инвариант `Restrict(Prolong(L)) = L` для аффинной локальной функции;
- знаковые свойства R-union/intersection/difference;
- пересечение плоскости `x=0` с кубом даёт корректный четырёхугольник на `L(x)=0`.

## Важное ограничение

Это proof-of-concept научной идеи, а не заявление о завершённой теории. Текущий `Restrict` использует усреднение локальных коэффициентов. Диссертационная часть должна формально определить оптимальные операторы prolongation/restriction, common refinement несовпадающих деревьев и оценки ошибки R-операций. Сам демонстратор уже содержит необходимую наблюдаемую геометрию и численные метрики для этих экспериментов.
