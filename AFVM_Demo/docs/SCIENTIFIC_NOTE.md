# Scientific note: от демонстратора к диссертационному аппарату

## 1. Объект исследования

Неоднородное дискретно-непрерывное пространство функционально-воксельных локальных моделей

`Ω_A = {(Ω_i, c_i, h_i, L_i, N_i)}`,

где `Ω_i` — область действия элемента, `c_i` — центр, `h_i` — локальный масштаб, `L_i` — локальная функция, `N_i` — локальные геометрические характеристики.

В текущем коде `L_i` линейна, а `N_i=(n_x,n_y,n_z,d)` соответствует нормализованной локальной плоскости нулевого уровня.

## 2. Прототип операторов P и Q

`LocalLinearFunction.Prolong()` реализует P для линейной локальной функции: перенос той же функции в центр дочернего элемента.

`LocalLinearFunction.Restrict()` реализует минимальный Q: среднее значений дочерних функций в центре родителя + средний градиент.

Self-test проверяет точный инвариант для любой affine-функции:

`Q(P(L)) = L`.

Для диссертации Q должен быть заменён оптимизационной постановкой, например

`argmin_L [ α E_value + β E_gradient + γ E_R ]`,

с доказанными оценками.

## 3. Ключевой эксперимент с R-алгеброй

Строятся `A_h` и `B_h` независимо. Затем

`C_h = Adapt( R(A_h, B_h) )`.

Сравнение выполняется с

`C = R(A, B)`.

Измеряются:

- геометрическая ошибка нулевого уровня;
- ошибка локальной нормали;
- число элементов;
- позже: ошибка после последовательности R-операций и restriction/prolongation.

Это первая программная форма вопроса:

`P(R(A,B)) ?≈ R(P(A),P(B))`.

## 4. Почему это не просто adaptive octree

Octree отвечает только на вопрос хранения областей разного масштаба. Научная задача находится в другом месте:

1. какие локальные характеристики должны сохраняться при смене масштаба;
2. как определять P/Q для ФВ-локальной функции;
3. как выполнять R-операции на несовпадающих разбиениях;
4. как оценивать ошибку R-результата после P/Q;
5. какие условия обеспечивают непрерывность и сходимость.

Поэтому дерево в коде должно оставаться заменяемой структурой данных.

## 5. Следующие эксперименты

1. Common refinement двух независимых деревьев без повторной адаптации по sample-error.
2. Несколько вариантов Q: average, weighted least squares, constrained normal fit.
3. Метрика `E_R` после цепочки из 10–100 R-операций.
4. Проверка affine/quadratic/polynomial/analytic test families.
5. Непрерывность между leaf разных уровней.
6. `h`-адаптация по апостериорной оценке вместо сравнения с source samples.
7. После стабилизации — M-image encoding и влияние квантования.
