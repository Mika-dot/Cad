# FVM × 3D FEM — автономный C# эксперимент

Статус: **исследовательский прототип**, не расчётная САПР и не доказательство технологической пригодности детали. Все новые исходники — только в `experiments/FvmGenerativeDemo/`. Зависимость: исходное `src/DCad.FunctionalVoxel/` ядро (без копирования реализации пяти M).

## Запуск (.NET 8, Windows/Linux)

```powershell
git fetch origin
git switch feature/fvm-generative-mechanics
dotnet build experiments/FvmGenerativeDemo/FvmGenerativeDemo.csproj -c Release
dotnet run --project experiments/FvmGenerativeDemo/FvmGenerativeDemo.csproj -c Release -- --self-test --out output/fvm-selftest
dotnet run --project experiments/FvmGenerativeDemo/FvmGenerativeDemo.csproj -c Release -- --iterations 3 --out output/fvm-demo
```

`--self-test` не открывает GUI, проверяет геометрию, эталон растяжения и два замкнутых изменения формы; ненулевой код выхода означает FAIL. `--iterations` 1–20. В выходном каталоге: `metrics.csv`, `comparison.txt`, BMP по трём Z-срезам до/после/изменение и десять изображений M0…M4. Каналы M представлены серыми оттенками на малой исходной сетке, а не увеличенными RGB24 коэффициентами; все внутренние коэффициенты остаются double.

### Физическая задача

Стержневая соединительная деталь по оси X, `L=100 mm`, с гладкой радиальной поверхностью
```
r(x)=8.5 - p0*sin(pi*x/100)^2 - p1*sin(pi*x/100)^4
F(x,y,z)=r(x)^2-y^2-z^2
```

`F>0` — материал, `F=0` — граница; `F<0` — пустота. Положительные `p0,p1` уменьшают центральное сечение, а опорный и нагрузочный интерфейсы при `x=0,100` имеют точно неизменный радиус 8.5 mm. Эти два параметра — *ограниченный подпространственный shape-design*; свободная оптимизация произвольной формы пока не реализована.

Модуль Юнга `200000 MPa`, коэффициент Пуассона `0.30`, сила `+1000 N` в X, `u=(0,0,0)` на всей плоскости X=0, правая сила распределена по узлам площадки `|y|,|z|<=4.1 mm`. Демонстрационная фоновая сетка `8 × 6 × 6` Hex8, `2×2×2` Gauss; область `[0,100]×[-12,12]×[-12,12] mm`.

Интеграл жёсткости на каждом элементе: `Ke = Σ_g w_g detJ [E_min/E+(1-E_min/E) H_epsilon(F_g)] B_gᵀ D B_g`. Используется `H_epsilon(F)=clip(0.5+F/(2*30),0,1)`, и `E_min/E=1e-5` исключительно для численной невырожденности. Поле `F_g` вычисляется через `FunctionalVoxelModel.Approximate` из пяти M, **не** по бинарному состоянию центра элемента. Это регуляризованная фоновая FEM, **не** точная интеграция по вырезанному полигону, не CutFEM/Nitsche и не физически строгое разделение материала/пустоты.

Решатель — матрично-свободный Jacobi-PCG с суммированием локальных 24×24 матриц, вычислением абсолютной реакции опоры и невязки свободных степеней свободы. Напряжения — Dε по Мизесу в восьми точках Гаусса; максимум берётся лишь по точкам с `H>=0.5`, исключая искусственную «пустоту» из максимума. Податливость — `fᵀu`. Масса из объёма и `7850 kg/m³`; ограничения `VMmax<=100 MPa`, `|u|max<=0.030 mm` относятся только к этому эксперименту, не к сертифицированным деталям.

Оптимизатор рассчитывает конечными разностями по `p0,p1` значения `dV/dp`, `dVMmax/dp`, `d|u|max/dp`, ограничивает предсказанный шаг по механическим производным и повторно решает FEM на новом поле, с backtracking и приёмом лишь *фактически* допустимого шага, уменьшающего объём. После каждого принятого шага пересоздаёт пять M и сверяет значения/градиенты с аналитической F в центрах решётки. Никакого `target_volume_ratio`, SIMP/OC или удаления процента кубов нет. Стоп без прогресса честно печатается как невыполненное улучшение.

### Независимые численные контроли

1. Призматический стержень `100×10×10 mm`, `E=200000 MPa`, `nu=0` (отсутствие поперечного эффекта у закреплённого торца), `P=1000 N`, распределённая торцевая тяга: `sigma_x=10 MPa`, `delta_x=0.005 mm`; `R_x=-1000 N`; `V=10000 mm³`.
2. Пространственная решётка `(5,4,3)` с индексацией C# `(i*ny+j)*nz+k` и проверка линейного F, градиентов, пяти коэффициентов нормированной касательной гиперплоскости, R-разности и R-объединения.
3. Сравнение FEM при исходном `F` напрямую из аналитической формулы и через реконструкцию `F` из пяти M на идентичной FEM-сетке; результаты пишутся в `comparison.txt`. Это контроль ошибки ФВ-реконструкции, **не** сравнительный эксперимент с SIMP.
4. Каждый принятый шаг подтверждается повторной FEM-оценкой реакции, относительной невязки, объёма, напряжения и перемещения.

### Ограничения и дальнейшие эксперименты

- Пока нет количественного сравнения с оригинальным `FEM_Voxel` Python/SIMP: отличаются геометрия, шаги, типы нагрузки и целевая функция; сравнение будет иметь смысл лишь при общей сцене и материалах.
- Нет точного интегрирования разрезанных элементов, проверки сходимости по mesh/epsilon/emin, удаления призрачной жёсткости `E_min`, обобщённых запретных зон, зарождения внутренних полостей, adjoint, сходимости в топологически различных конфигурациях, многонагруженности.
- Максимум напряжения на дискретных точках Гаусса — не гарантированный глобальный максимум; это особенно существенно около закрепления и концентратора.
- `FunctionalVoxelModel.Approximate` не равен исходной аналитической F в произвольных точках; различия отдельно измеряются.
- Для промышленного применения необходимы сеточная сходимость, независимая проверка FEM в CalculiX/Code_Aster и инженерная верификация пределов.

## Новый режим: генерация соединения двух сфер в 3D

Это **отдельная экспериментальная сцена**; старый режим стержня и его тесты сохранены.
Сфера A: центр (0,0,0), R=10 мм; сфера B: центр (80,0,0), R=10 мм.
Область первой сферы внутри R=8 мм служит закреплением, на узлы второй области R=8 мм
распределяются две составляющие силы (по умолчанию Fx=1200 Н, Fy=180 Н).

Пример Windows PowerShell:

```powershell
dotnet run --project experiments/FvmGenerativeDemo -c Release -- --two-spheres --self-test --out output/spheres-test
dotnet run --project experiments/FvmGenerativeDemo -c Release -- --two-spheres --iterations 10 --out output/spheres
# Настройка силы, модуля Юнга и ограничений:
dotnet run --project experiments/FvmGenerativeDemo -c Release -- --two-spheres --iterations 10 --force-x 1200 --force-y 180 --young 200000 --stress-limit 200 --displacement-limit 0.08 --out output/custom
```

Исходная конструкция — цилиндрический мост, геометрически объединённый с двумя
сферами гладкой функциональной композицией (soft R-подобное объединение).
**54 независимых пространственных базисных функций** (шесть станций по X,
3×3 по Y/Z) меняют единое непрерывное неявное поле F, в том числе могут
создавать неосесимметричную форму. Это не вычитание заданного процента
низкоэнергетических вокселей. Из F и его трёх производных последовательно
восстанавливаются нормированные пять M-образов; FEM собирается по
`FunctionalVoxelModel.Approximate` на восьми точках Гаусса каждого Hex8.

Градиент объёма и **сопряжённый градиент податливости**
`dC/dFq = -uᵀ (dK/dFq) u` вычисляются из точек интегрирования,
затем проектируются на параметры непрерывного F через дифференцируемую
реконструкцию M-плоскостей. Тест сравнивает эти производные с центральными
разностями полного повторного FEM-решения. Полный FEM-пересчёт каждого
пробного шага является обязательным; шаг принимается только при уменьшении
объёма, соблюдении предельных `VMmax` и `u_max`, равновесии и наличии
связи между сферами на дискретной ФВ-сетке.

**Результаты запуска:** `optimized.stl` и `initial.stl` (триангуляция
функциональной поверхности marching tetrahedra с шагом 2 мм), `metrics.csv`,
`summary.txt`, BMP до/после в трёх Z-срезах и M0...M4. STL — исходная
инженерная геометрия для дальнейшей проверки; технологичность для FDM,
минимальные стенки, связность STL на треугольном уровне и отсутствие
дефектов сетки отдельно не удостоверены.

**Границы текущего режима:** сферы и их центры заданы демонстрационной
конфигурацией в коде; параметры CLI управляют силами/материалом/ограничениями,
но полноценного редактора STEP/поверхностей или произвольных закреплений нет.
54 гауссовых базиса дают пространственную свободу, но не произвольную
топологию и не глобальный минимум массы. Связность проверяется по
6-соседним положительным узлам ФВ-объёма; это дискретный критерий, а не
доказательство непрерывной связности. МКЭ использует размытую границу
`epsF=2 мм` и численную жёсткость пустоты `Emin/E=1e-4`;
расчёт требует сеточной сходимости и независимой инженерной проверки.
